# Cancel Sit Flow

A 3-step flow for pet owners cancelling an upcoming sit.

## Steps
1. Select cancellation reason
2. Review cancellation policy and confirm
3. Cancellation confirmed

## Notes
- Mock sit data is in data.ts
- All cancellation reasons are configurable via data.ts
- The "Other" option reveals a freetext input
- Step 2 uses the Banner component for the policy warning
